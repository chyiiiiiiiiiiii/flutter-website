# Flutter 支援

> 開發 Flutter 時可以獲得哪些支援資源。



歡迎！

在開發 Flutter 時，有許多不同的方式可以獲得支援。
由於 Flutter 是一個開源專案，
你可以選擇在遇到軟體錯誤時回報問題，
也可以與在地社群交流，
或是瀏覽、尋找提供支援服務的商業代理商與顧問名單。

## 我想回報 Flutter 的問題

請參考如何[建立有用的錯誤回報](/resources/bug-reports)。
請注意，提交錯誤回報並不是獲得技術支援的高效方式。

## 我想詢問如何使用 Flutter

你可以優先考慮
[Flutter Forum](https://forum.itsallwidgets.com/)、
[Stack Overflow](https://stackoverflow.com/questions/tagged/flutter)，
或 [Discord](https://discord.com/invite/rflutterdev)。
雖然社群在這些管道都很活躍，
但這些平台對於新貼文或聊天室訊息的回覆，沒有官方的服務等級協議（SLA）。

## 我想獲得 Flutter 的專業服務支援

請參考
[Flutter 顧問](https://flutter.dev/consultants)
目錄。

## 我想獲得 Flutter 專家的支援

Google 擁有一群 [Google Developer Experts][] (GDEs)，
他們並非 Google 員工，但在 Flutter、Dart 等 Google 技術領域具有專業知識。
GDE 並非免費顧問，但他們經常舉辦講座、社群聚會、工作坊或製作教學影片。
作為 Dart 與 Flutter 全球社群的一部分，
他們是非常寶貴的資源。

[Google Developer Experts]: https://developers.google.com/community/experts/directory?specialization=dart%2Cflutter

## 我想獲得 Google 或 Flutter 專案的付費支援

由於我們是開源專案，
無法直接提供付費支援服務。
我們建議你參考
[顧問計畫](https://flutter.dev/consultants)。
