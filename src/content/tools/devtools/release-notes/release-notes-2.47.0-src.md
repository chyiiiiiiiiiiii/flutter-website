# DevTools 2.47.0 版本發佈說明

Dart 與 Flutter DevTools 2.47.0 版本
除了其他一般性改進外，包含以下變更。
想進一步了解 DevTools，請參閱
[DevTools overview](/tools/devtools/overview)。

- 修正了在主控台複製所有日誌時，任何被檢查的元件 (Widgets) 會顯示為 `null` 的問題。 - [#9204](https://github.com/flutter/devtools/pull/9204)
