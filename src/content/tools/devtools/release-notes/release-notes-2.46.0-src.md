# DevTools 2.46.0 發行說明

Dart 與 Flutter DevTools 2.46.0 版本
包含以下變更及其他一般性改進。
想進一步了解 DevTools，請參閱
[DevTools overview](/tools/devtools/overview)。

## 一般更新

- 修正了一個導致 Web 應用程式在從 DevTools 觸發 hot-restart 後仍然保持暫停狀態的錯誤。- [#9125](https://github.com/flutter/devtools/pull/9125)
- 新增變更，當已連線的應用程式狀態改變時，自動關閉過時的橫幅訊息。- [#9148](https://github.com/flutter/devtools/pull/9148)
- 修正搜尋欄位的焦點移動問題。[#9166](https://github.com/flutter/devtools/pull/9166)

## 效能更新

- 修正了當連線至暫停中的 Flutter 應用程式時，Performance 頁面會卡住的問題。- [#9162](https://github.com/flutter/devtools/pull/9162)
