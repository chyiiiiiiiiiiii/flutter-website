# DevTools 2.28.4 發行說明

Dart 與 Flutter DevTools 2.28.4 版本
包含以下變更及其他一般性改進。
如需進一步了解 DevTools，請參閱
[DevTools overview](https://docs.flutter.dev/tools/devtools)。

本次為基於 DevTools 2.28.3 的 cherry-pick 發行版本。
如需瞭解 DevTools 2.28.3 所包含的改進，請參閱
[release notes](/tools/devtools/release-notes/release-notes-2.28.3)。

## 檢查器（Inspector）更新

* 在檢查設定對話框中，新增了導向套件目錄（package directory）文件的連結 - [#6825](https://github.com/flutter/devtools/pull/6825)

* 修正了一個 Flutter framework 所擁有的元件（Widgets）會出現在元件樹（widget tree）檢視中的錯誤 -
[#6857](https://github.com/flutter/devtools/pull/6857)

## 完整提交記錄

如需查閱本次發行的完整變更清單，請參閱
[DevTools git log](https://github.com/flutter/devtools/tree/v2.28.4)。
