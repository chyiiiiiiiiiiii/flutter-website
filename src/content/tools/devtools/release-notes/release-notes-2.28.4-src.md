# DevTools 2.28.4 版本發行說明

Dart 與 Flutter DevTools 2.28.4 版本
包含以下變更及其他一般性改進。
想進一步了解 DevTools，請參閱
[DevTools overview](https://docs.flutter.dev/tools/devtools)。

本次為基於 DevTools 2.28.3 的 cherry-pick 版本發行。
若想了解 DevTools 2.28.3 所包含的改進，請閱讀
[release notes](/tools/devtools/release-notes/release-notes-2.28.3)。

## 檢查器（Inspector）更新

* 在檢查設定對話框中，新增指向套件目錄（package directory）文件的連結 - [#6825](https://github.com/flutter/devtools/pull/6825)

* 修正一個錯誤，該錯誤導致由 Flutter 框架所擁有的元件（Widgets）會顯示在元件樹檢視中 -
[#6857](https://github.com/flutter/devtools/pull/6857)

## 完整提交紀錄

如需本次發行的完整變更清單，請參閱
[DevTools git log](https://github.com/flutter/devtools/tree/v2.28.4)。
