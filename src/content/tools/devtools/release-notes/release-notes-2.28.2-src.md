# DevTools 2.28.2 版本更新說明

Dart 與 Flutter DevTools 2.28.2 版本
包含以下變更及其他一般性改進。
想進一步了解 DevTools，請參閱
[DevTools overview](https://docs.flutter.dev/tools/devtools)。

本次為 DevTools 2.28.1 基礎上的 cherry-pick 版本。
若想了解 DevTools 2.28.1 中包含的改進，請閱讀
[release notes](/tools/devtools/release-notes/release-notes-2.28.1)。

## DevTools Extension 更新

* 當偵錯不在 `lib` 下的 Dart 進入點（例如單元測試或整合測試）時，啟用 DevTools 擴充功能。感謝
  [@bartekpacia](https://github.com/bartekpacia) 的貢獻！-
  [#6644](https://github.com/flutter/devtools/pull/6644)
