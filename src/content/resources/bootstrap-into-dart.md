剛接觸 [Dart][Dart] 語言嗎？
我們整理了最推薦的學習資源，
幫助你快速上手 Dart。
許多人都表示
[Dart 很容易學且很有趣][Dart is easy and fun to learn]。
我們也希望這些資源能讓你輕鬆學會 Dart。

[語言導覽（Language tour）][Language tour]
: 最適合入門 Dart 語言的介紹。
  你將學到 Dart 的特色，例如 _強型別_、
  _閉包_、_函式庫（libraries）_、_詞彙作用域（lexical scoping）_、
  _頂層函式（top-level functions）_、_具名參數（named parameters）_、
  _async / await_ 等等。

[函式庫導覽（Library tour）][Library tour]
: 全面了解 Dart 強大核心函式庫的好選擇。
  學習 Dart 在集合、非同步、數學、數字、字串、JSON 等方面的支援。

[JavaScript 開發者學 Dart（Learning Dart as a JavaScript developer）][Learning Dart as a JavaScript developer]
: 利用你現有的 JavaScript 知識，快速上手 Dart。
  了解兩種語言之間的主要相似與差異，
  以及 Dart 中一些在原生 JavaScript 沒有的概念和慣例。

[Effective Dart][Effective Dart]
: 關於程式風格、文件撰寫、使用方式等的最佳實踐指南。

[非同步程式設計：futures、async、await][Asynchronous programming: futures, async, await] codelab
: 學習如何使用 futures 以及 `async` 和 `await` 關鍵字撰寫非同步程式碼。

[非同步程式設計：streams][Asynchronous programming: streams]
: 學習如何利用 streams 進行非同步 I/O 與事件處理。

想了解更多甚至參與貢獻嗎？
歡迎參加 [Dart 社群][Dart community]。
