## 一切是如何開始的？

當 Shams Zakhour 於 2013 年 12 月開始在 Google 擔任 Dart 文件撰寫者時，
她就開始倡議為 Dart 設計一個吉祥物。
在撰寫 Java 文件 14 年的過程中，她觀察到 Java 吉祥物 [Duke][Duke]
受到大家的喜愛，因此她也希望 Dart 有個類似的代表。

[Duke]: https://www.oracle.com/java/duke.html

不過這個想法直到 2017 年才開始受到關注，
當時一位 Flutter 工程師 Nina Chen 在內部郵件列表上提出了這個建議。
當時的 Flutter 副總裁 Joshy Joseph
批准了這個想法，並請 [2018 Dart Conference][2018 Dart Conference]
的主辦人 Linda Rasmussen 來推動這個計畫。

[2018 Dart Conference]: https://events.dartlang.org/2018/dartconf/

當 Shams 得知這個計畫後，
她立刻找到 Linda，主動要求負責並推動
為大會製作絨毛玩偶的專案。
Linda 已經取得了一些設計草圖，並交給了她。
Shams 以這些草圖為起點，找到了一家能在緊迫期限內（與農曆新年撞期）配合的廠商，
開始著手製作絨毛玩偶的規格。

沒錯，Dash 最初其實是
**Dart** 的吉祥物，而不是 Flutter 的吉祥物。

## 為什麼選擇蜂鳥？

在早期，Dart 團隊為簡報與網頁設計了一個蜂鳥圖像。
蜂鳥象徵 Dart 是一個高速的語言。

![Early hummingbird drawing](/assets/images/dash/DartHummingbird.jpg){:width="35%"}<br>

然而，蜂鳥的外型尖銳且有稜角，
但我們想要一個可愛的絨毛玩偶，因此選擇了圓潤的蜂鳥造型。

Shams 指定了各部位的顏色、尾巴形狀、頭頂毛束、眼睛等細節。
廠商將規格發給兩家製造商，幾週後收到了原型。

![The first Dash prototypes](/assets/images/dash/dash-prototypes.jpg){:width="35%"} ![The first Dash prototypes](/assets/images/dash/dash-prototypes2.jpg){:width="35%"}<br>

{% ytEmbed 'R5vIUjRZaZA', 'Introducing Dash at the January 2018 Dart Conference' %}

在生產過程進行的同時，
Shams 為絨毛玩偶取了名字：Dash。
這個名字曾是 Dart 專案的早期代號，性別中性，
而且對蜂鳥來說也很貼切。

許多箱 Dash 絨毛玩偶剛好在大會前
抵達南加州。Dart _和_ Flutter 愛好者都非常喜愛。

大家的選擇讓 Dash 現在成為 Flutter **與** Dart 的吉祥物。

![Dash 1.0](/assets/images/dash/dash-1.0.jpg){:width="35%"}<br>
Dash 1.0

![Piles of Dashes awaiting conference goers](/assets/images/dash/dash-conference-swag.jpg){:width="50%"}<br>
大會贈品

自 Dash 1.0 誕生以來，我們又推出了兩個版本。
Dash 1.0 推出後，行銷團隊稍微調整了 Dart 與 Flutter 的配色方案，
因此 Dash 2.0 採用了新版配色（移除了綠色）。
Dash 2.1 則尺寸更小，顏色也有些微調整。
較小的尺寸更方便運送，也更適合夾娃娃機！

* Dash 是女性，但她不介意被稱為 _they_、_their_、_he_ 或 _him_。
* Dash 有一個 [Instagram 帳號][Instagram account]。
* Dash 的喙是**直的**。
