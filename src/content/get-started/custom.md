若要開始使用 Flutter 進行開發，
請依照下列步驟安裝並設定 Flutter，
以符合您偏好的開發環境與目標平台。

如果您打算使用 VS Code 或其他基於 Code - OSS 的編輯器，
建議您改為參考 [Flutter 快速入門][Flutter quick start]。

[Flutter quick start]: /get-started/quick

## 安裝並設定 Flutter {: #install}

若要開始使用 Flutter 開發應用程式，
請將 Flutter SDK 安裝到您的開發裝置上。

## 設定目標平台 {: #target-platform}

以持續您的 Flutter 學習之旅。

我們建議您先[開發 Web 應用程式][web-setup]{: target="_blank"}，
因為除了安裝合適的瀏覽器外，無需額外設定。
您隨時可以為其他目標平台設定開發環境。
