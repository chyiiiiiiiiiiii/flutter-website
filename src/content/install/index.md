## 更新 Flutter {: #update}

如果你已經安裝過 Flutter，並希望
升級 Flutter SDK（Flutter 軟體開發套件）或切換至不同的發行頻道，
請參考[升級 Flutter][Upgrading Flutter]。

升級時，也請記得參閱已發布的
[重大變更與遷移指南][breaking changes and migration guides]。

[Upgrading Flutter]: /install/upgrade
[breaking changes and migration guides]: /release/breaking-changes

## 下載舊版發行版本 {: #previous-releases}

如果你需要下載並安裝 Flutter 的舊版發行版本，
請參考[SDK 歷史版本存檔][SDK archive]。

:::note
我們建議你將應用程式與開發環境
保持在**最新**的 `stable` 或 `beta` 發行版本。
:::
