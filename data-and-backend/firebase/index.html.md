# Firebase

> 如何在 Flutter 中使用 Firebase 與 Firestore。



Firebase 是一個後端即服務 (Backend-as-a-Service，BaaS) 應用程式開發平台，
提供託管的後端服務，例如即時資料庫、雲端儲存、驗證、崩潰回報、機器學習、
遠端設定，以及靜態檔案的託管。
